# Student Task Manager

## Project Description
A simple web application developed to demonstrate a real collaborative Git and GitHub workflow. The application allows users to add tasks, display tasks, mark tasks as completed, delete tasks, and search tasks.

## Features
- Add new tasks with title and description
- Display list of tasks
- Mark tasks as completed
- Delete tasks
- Search tasks

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Git & GitHub

## Git Workflow
1. Initialized local repository and created initial commits.

3. Created feature branches for different tasks (form, styling, search).
4. Performed code reviews and merged Pull Requests.

## How to Run
1. Clone the repository: `git clone https://github.com/Arooj-Basharat/student-task-manager.git`
2. Open `index.html` in any modern web browser.
3. No additional installation is required.
